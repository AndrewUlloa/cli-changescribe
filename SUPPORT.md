# Support

## Getting help

1. Run `diffwright doctor` from the affected repository.
2. Check the [troubleshooting guide](https://github.com/AndrewUlloa/diffwright/blob/main/documentation/troubleshooting.md).
3. Review command help with `diffwright <command> --help`.
4. Search [existing issues](https://github.com/AndrewUlloa/diffwright/issues).

If the problem remains, open a GitHub issue with the Diffwright version, Node
version, operating system, command, provider/model names, safe diagnostic
category, and a minimal reproduction. Remove credentials and proprietary code.

## Security

Do not report a security vulnerability in a public issue. Follow the
[security policy](https://github.com/AndrewUlloa/diffwright/blob/main/SECURITY.md)
and use the private advisory form.

## Provider and billing support

Authentication, quota, billing, model availability, and retention questions
usually belong with the selected provider or gateway. Diffwright can identify
the resolved endpoint and categorize its response but cannot inspect provider
accounts.
